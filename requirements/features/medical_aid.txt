## 🏥 Feature: Integrated Medical Aid & Co-Payment Processing

### Feature Overview
To eliminate manual invoicing and unexpected out-of-pocket costs, the Family Clinic Dashboard includes an integrated **Medical Aid & Benefit Verification System**. This module allows patients to link their health insurance plans directly to their family profiles, enabling real-time claim validation, automated network rate processing, and dynamic co-payment calculations at checkout.

---

### 👤 User Flow & Interface Requirements

#### 1. Medical Aid Integration & Profile Setup
Patients manage their family insurance coverage directly from their profile dashboard.
*   **Provider & Plan Mapping:** A searchable dropdown containing recognized South African medical schemes (e.g., Discovery Health, Momentum, Bonitas) and their respective tier plans.
*   **Family Dependency Hierarchy:** Main members can input membership details once and map specific dependents (spouse, children) to their respective profiles for accurate claims routing.
*   **Digital Card Upload:** Secure document upload interface (PDF/JPEG) for digital membership cards to serve as clinic verification records.

#### 2. Live Switch Verification (Backend APIs)
Upon submission, the dashboard initiates a live background check via a medical switch API gateway (e.g., Healthbridge / MediSwitch):
*   **Status Indicators:** Displays a dynamic UI badge showing validation states: `[🟢 Active / Verified]`, `[🟡 Pending Verification]`, or `[🔴 Check Coverage / Invalid Details]`.
*   **Pre-Authorisation Engine:** Automated system triggers for specialized consultations or minor clinical procedures, providing patients with a clinic token to submit to their provider.

#### 3. Dynamic "In-Network" Checkout Calculations
The dashboard removes the concept of "discount codes" and replaces it with automated tariff rate processing.

| Transaction Type | Patient Action | System Logic & UI Display |
| :--- | :--- | :--- |
| **Consultation Booking** | Selects a Practitioner. | Checks **Designated Service Provider (DSP)** status. Displays: *"In-Network rate applied: 100% covered by scheme."* |
| **Bill Payment** | Proceeds to Checkout. | Computes co-payment split. <br>• **Gross Cost:** R550.00 <br>• **Scheme Covered:** -R450.00 <br>• **Payable Out-of-Pocket:** R100.00 |
| **Pharmacy / Refills** | Orders Prescriptions. | Cross-references the scheme's **Formulary List**. Suggests generic substitutes to guarantee maximum coverage. |

#### 4. Patient Value-Add Features
*   **Medical Savings Account (MSA) Widget:** A dashboard visualizer displaying estimated remaining day-to-day funds to preemptively flag self-payment gaps.
*   **Wellness & Rewards Integration:** Automated logging of clinic screenings to unlock incentive-based funds (e.g., Bonitas Booster, Momentum Multiply, Discovery Vitality metrics).

---

### 🛠️ Technical Implementation Notes (For Developers)

*   **Database Schema Requirements:** 
    *   `medical_aid_providers` table mapping scheme names, plan tiers, and switch codes.
    *   `patient_insurance_profiles` linking `user_id` or `dependent_id` to scheme data, encryption keys for member IDs, and digital card blob pointers.
*   **Security & Compliance:** All medical aid data, identity numbers, and uploaded cards must be encrypted at rest and in transit, complying strictly with **POPIA** (Protection of Personal Information Act) and **HIPAA** standards.
*   **External Integrations:** Webhook listeners must be configured to handle asynchronous response payloads from the medical switch during real-time authorization requests.

## 🏥 Medical Aid Integration & Patient Checkout Flow

To ensure an intuitive experience for families managing healthcare costs, the platform does not treat medical aid like a traditional retail discount code. Instead, savings are realized through **real-time scheme validation**, **in-network rate alignment**, and **automated co-payment calculations**.

### 1. Account Onboarding & Dependent Mapping
Before booking or purchasing services, patients link their healthcare coverage under **Account Settings > Medical Aid Info**:
* **Scheme Selection:** A dynamic dropdown populated with recognized regional medical aid providers (e.g., Discovery Health, Momentum, Bonitas).
* **Credential Validation:** Fields for the Main Member ID, Medical Aid Scheme Option/Plan, and Membership Number.
* **Dependent Allocation:** For family accounts, the primary member maps specific dependents to the policy. This ensures claims are routed to the correct individual profile.
* **Digital Card Upload:** An image upload component (supporting JPEG, PNG, or PDF) to save a digital copy of the physical medical aid card for clinic administrative verification.

### 2. Live API Verification & Benefit Tracking
Once saved, the system connects via an API switch (e.g., Healthbridge / MediSwitch) to perform background checks:
* **Active Status Badge:** Displays a live green verification badge once the scheme confirms the membership is active.
* **Pre-Authorisation Alerts:** Automated warnings trigger if a selected procedure or specialized consultation requires explicit pre-authorisation from the provider.
* **Medical Savings Account (MSA) Widget:** A dashboard utility showing remaining day-to-day funds to help families anticipate self-payment gaps.

### 3. Integrated Checkout & "Discount" Breakdown
Instead of entering promo codes, the patient's checkout experience dynamically calculates out-of-pocket costs based on network rates and formulary limits.

| Touchpoint | System Logic | Patient-Facing Result |
| :--- | :--- | :--- |
| **Booking a Consult** | Checks if the clinic/practitioner is a **Designated Service Provider (DSP)** or "In-Network" for the selected plan. | Displays a banner: <br>`✓ In-Network rate applied: 100% covered by scheme.` |
| **Payment Finalisation** | Submits a real-time pre-claim query to check available funds. | Breaks down the invoice:<br>• **Total Cost:** R400.00<br>• **Covered by Scheme:** -R400.00<br>• **Due Now:** R0.00 |
| **Medication Refills** | References the scheme's preferred drug formulary list. | Automatically suggests alternatives: <br>`💡 Generic substitute selected to avoid co-payment.` |

### 4. Wellness & Loyalty Rewards Integration
The dashboard integrates with major wellness/incentive programs (e.g., Momentum Multiply, Bonitas Benefit Boosters) to add value:
* **Automated Claims Processing:** Completing preventative care or basic screenings at the clinic automatically logs the event to trigger health reward points.
* **Benefit Unlocks:** Successful screening outcomes dynamically update the dashboard to reveal newly unlocked scheme-funded benefits.
